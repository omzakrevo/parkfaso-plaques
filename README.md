# PARKFASO — Application gardien

Entrée des véhicules (moto, voiture, tricycle, vélo), lecture des plaques par la caméra
(hors ligne), tickets thermiques Bluetooth en deux temps, scan des tickets à la sortie.

Voir **[INTEGRATION.md](INTEGRATION.md)** pour l'installation, l'imprimante et les tests.

```bash
flutter pub get
flutter test
flutter build apk --release
```
